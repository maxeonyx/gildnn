## On what the predictive processing model fundamentally is

What I'm trying to get here is a predictive processing model. The predictive processing model takes a swath of inputs at time step A and the immediate internal neighbours predict those inputs at time step B. That's the very fundamental start of it. Then we additionally have deeper nodes that are not directly connected to the inputs and or outputs, but yet they still help somehow, and that is all a big hypothesis space.

## On attention-based residuals

Separately, but something I'm very interested in is using attention-based residuals. So instead of a normal summative residual chain, using an attention over depth. I kinda think this is very similar to my model actually already. And I also think it's kind of the same as my mix add operator, which uses a sigmoid which is simply a binary attention mechanism, I think? But we can generalize this, rather than using mix add we can use attention over all previous residual layers. Or even over a causal triangle across depth and timesteps. This might simplify our architecture, so instead of having messages, we essentially have a big attention combination. Not sure exactly what this means, and I'm still very partial to having things be local where possible because that makes them be able to be parallel. But I'm imagining, for example, an RNN where it has an attention mechanism over its inputs and over its own previous state outputs. I'm not so keen on these gated recurrent units or LSTMs or things like that. Somehow they are not appealing to me. I'd much rather a dumber RNN. We can at least try it.
