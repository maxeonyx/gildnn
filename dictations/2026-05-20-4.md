## On the predictive chain architecture vs my actual vision

One thing that is wrong with this architecture is that the predictive chain here is input on one end and output on the other, and that's not correct for my model. The architecture I have in mind has each modality as both input and output on one end of the chain. The far end of the chain in this example would be completely unhooked. It would not be connected to the input except simply by its neighbours. It's simply not a feedforward chain. The very first node connected to the input is predicting that input at the next step, and that is the output here. The deeper nodes, well we have to see how they work, that's the experiment. Do they learn interesting things, even given they're not directly connected on any particular chain? Each node is producing messages and learning somehow which messages to produce to make its neighbors produce good messages for it at the next stage. Let's think about exactly how far we need the gradients to go in order for that to work.
