## Modularity / noise gates (from separate Keep note "Project #ideas")

Definition for modularity? Outputs use the minimum number of modules. What defines a module? An attention head, a residual block etc. Regularize the network so that it can soft-turn-off the module. How to soft-turn-off the module? Some differentiable way of restricting the bit-rate in a channel. Maybe a mix parameter between the activations and a noise vector input? Setting the mix parameter to low-noise is penalized? "Noise gates" - add noise, reduce norm. Activations can't pass through, because of noise. But the noise doesn't screw up the residual layer because it's gated out, with a different function of the same parameter.
