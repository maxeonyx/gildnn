Specifically:
1. A graph of nodes (start with a simple topology — grid or whatever)
2. Stale lateral communication between nodes
3. A central head that attends over all node states and produces token predictions
4. Multi-horizon CE loss (predict next token at various rollout depths)
5. Broadcast scalar reward from the head's CE loss back to nodes
6. A universal node objective — start with "predict your next inputs" since that's the candidate
7. Neighbourhood scalar signal (each node's loss available to neighbours, time-delayed)

Use the existing infrastructure (CUDA graphs, TinyShakespeare dataset, training loop). Don't overengineer — get the skeleton working and see what happens. The point is: does the broadcast scalar + neighbourhood signal + noise bottleneck produce representations the head can use? That's the experimental question.

Start simple. Get it running. Then iterate.
