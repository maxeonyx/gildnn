# Dictation 2026-05-26-2

## Stop the gradient-removal experiments. Redirect to actual local predictive loss.

The bridge_detach and warmup_detach experiments are answering a question that doesn't matter. "Does removing gradient make things worse?" — obviously yes. More information is always better. But we *can't have* global gradient in the async architecture. It's not an option. So proving it helps is irrelevant.

Twelve hours of GPU time on this. We have five days left. Every GPU hour from now needs to be heavily justified.

**What I actually want tested:**

The comparison points that matter are:
1. Transformer baseline (1.592) — the thing to beat
2. Single block with CE (~1.832) — minimum viable output-connected block
3. Multiple blocks where interior blocks train with local predictive loss only (no task gradient on interior blocks) — the actual architecture

The question is: does adding predictive-loss-trained interior blocks improve over a single CE-connected block? By how much? How does it compare to the transformer?

I don't care about comparing "full gradient" vs "less gradient." That's not a legitimate design option. Compare against legitimate alternatives — transformer, single block, etc.

**On the shared adjoint:** I don't think it's biologically plausible for all blocks to receive gradient from the cross-entropy loss. The biologically plausible thing is that inputs are handled by predictive processing (predict what's coming, learn from surprise), and outputs are handled by some kind of reward modelling. Interior blocks should get *only* local signals.

**On experiment length:** Don't run multi-hour multi-seed experiments to prove obvious things. Prove the mechanism works in minutes first. Scale up only when you have something worth scaling. Each hour of GPU time must be justified against what we could learn with a shorter run.

**Stop:** warmup_detach (if still running), tied_sharing rerun, predictive-residual as currently designed (it still keeps the shared adjoint).

**Start:** Implement the actual local predictive loss. Interior blocks predict what arrives laterally. Compare against single-block and transformer. Short runs first.
