# Dictation 2026-05-21-8

Some things to think about when swapping in Muon — not necessarily blockers, but worth checking:

**Getting Muon:** The canonical implementation has been a single-file script from Keller Jordan, but Muon has been gaining traction recently and may already be in PyTorch or a standard library. Check before copying in a standalone implementation.

**What it applies to:** Muon is designed for weight matrices. The standard recommendation is to use Muon for weight matrices and AdamW for everything else — embeddings, biases, scalars, output projection. So you'd likely need to split parameters into two groups with two optimizers. In this architecture that means Muon for the linear layers inside the feedforward block and attention, AdamW for embeddings, position embeddings, mix-add scalars (the alpha_logit parameters), and the output linear.

**Learning rate:** Muon uses a different effective learning rate scale than Adam. May need tuning, or at least start from recommended defaults.

These are things to think about and check, not assumed blockers.
