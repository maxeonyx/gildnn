## Research request: local learning rules for bidirectional chains

I'd like an agent to please answer this local learning question. What are the different ways we can do a local learning rule in a bidirectional information propagation where only one end of a chain has grounded input-output loss?

How does predictive coding work? How do other alternatives for local learning rules work? How can we test those?

Context: we have a chain of blocks. Only block 0 (one end) receives token input and has the next-timestep prediction loss. Interior blocks depend on lateral propagation for their input. Each block has two outputs — one going toward the input, one going away from the input. The question is: what local learning signal can interior blocks use so that they develop useful abstract representations without global backprop?

We already evaluated and rejected "attention-based usefulness" (being attended to ≠ being useful for the task). More principled alternatives are needed.
