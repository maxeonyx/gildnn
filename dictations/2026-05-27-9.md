# Dictation 2026-05-27-9

## Fixed embeddings — learned is an optimization, not a requirement

Do the embeddings have to be learnable? Can we just smash them around on a sphere and be done with it?

I think learned embeddings are an optimization — they improve performance, but they're not necessary. Start with fixed random unit vectors. This completely eliminates the gradient coupling question (nothing shared between blocks), eliminates collapse risk, and makes the blocks truly independent.

Learned embeddings can be added later once the architecture is proven. That's an optimization pass, not a design requirement.
