# 2026-05-25 evening — new design note on predictive processing and information flow

Max and I just had a long design conversation. A new research question write-up has been added:

**`research/questions/multi-timestep-architecture/README.md`**

This describes a refined architecture where:
- The grid has lateral positions × timesteps
- Blocks are temporal edges (not nodes) — they process and add delay
- The lateral flow IS the residual stream, unprocessed, no blocks on it
- The stream carries DISTRIBUTIONS, not point vectors
- Each block also outputs a distribution (its prediction)
- Surprisal (Wasserstein distance between lateral distribution and block's predicted distribution) is what flows rightward
- The block's prior flows leftward (right-to-left connections)
- Local loss = minimize Wasserstein distance between block's prediction and actual lateral input
- Extra timesteps per token are for right-to-left (processed) info to flow back, not for left-to-right (that's already fastest)

**Instruction from Max:** Please read this note and make sure your experiments are consistent with the direction implied by it. The current experiments (C_old ablation, tied weight sharing) are still valuable — they validate that lateral connections carry information and that the forward architecture works. But future experiment design should be informed by this new framing.

This doesn't invalidate current work. It provides the theoretical direction for what comes AFTER the current experiments confirm the basics.
