### Cumulative progress, not regression

I don't want to see our experiments regressing across eight dimensions as they go forward on one. We should be building more and more sophisticated things into the core. We should be using CUDA graphs by default. We should be using our proven pieces by default.

The proven pieces: CUDA graph training, dynamic depth/halting, weight-tied readout, normalized embeddings, recurrent depth, stale laterals. These are ALL validated. They should be the DEFAULT baseline that every experiment starts from. A new experiment ADDS a piece to this stack — it doesn't start from scratch with a flat GRU.

### Multi-rate blocks and TBPTT

Truncated backpropagation through time is easy if we have multi-rate blocks. We only need small numbers of BPTT steps if we have multi-rate blocks — because a higher block firing every Nth timestep effectively bridges N times the temporal extent within the same BPTT window.

We should think through what it means for a multi-rate block to be triggered — through surprisal or accumulation or something like that, rather than just a flat rate. But flat rate is a good start. Ideally: "fire when there's enough new information to warrant it." That might be an inference-time thing rather than a training-time thing.

Add multi-rate to the assembly.
