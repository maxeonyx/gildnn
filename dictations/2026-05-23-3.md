# Dictation 2026-05-23-3

I've just changed the dictation process. We're going to try using an OpenCode plugin for detecting dictations. This will be effective on the next loop of the autonomous loop. Do not revert these changes, keep them.

The old `core/check_dictations.py` polling approach is deleted. The new approach is `.opencode/plugins/dictation-notifier.ts` — it uses the `file.watcher.updated` event to detect new dictation files and injects a `[DICTATION NOTIFICATION]` message into the active session via `session.prompt(noReply: true)`. The agent sees it on its next turn and cannot miss it.
