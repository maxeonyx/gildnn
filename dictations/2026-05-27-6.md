## Examples of valid comparisons

Each of these is: take something that works, change ONE thing, see what happens.

- Take a model that definitely works → inject noise on the laterals. Does it still work? Does it help create timescale separation?
- Single block model vs single block model plus a far-lower-rate delayed observer. Does the observer learn anything from its local loss? (I think we already did something like this at some point.)
- With vs without CUDA graph. Does it give the expected speedup? (This should just be default.)
- A model that uses all blocks connected with global backprop vs the same model with local learning only. What changes? Do the blocks still learn? Do they learn different things?
- Different variants of the predictive loss idea — but only principled ones, no stupid unprincipled ones. What's the right loss for "predict further ahead"? Cosine? CE via tied readout? Something distributional?

These are all faithful to the final design. None of them involves training a broken model and analyzing it as if the results mean something.
