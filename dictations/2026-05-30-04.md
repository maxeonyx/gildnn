The loop agent was idling for over an hour while the GPU was running a training run. It wasn't keeping all three workstreams active. It was polling for checkpoints and verifying argument parsing instead of doing theory work or running ablations.

The GPU being busy is not an excuse to idle. The 3090 has 24GB — small ablations can coexist with a training run. Check nvidia-smi for free memory. If the GPU genuinely can't fit another experiment, run ablations on CPU. Tiny models proving a concept don't need GPU. If no ablation is runnable at all, theory track is mandatory. Polling, prepping, waiting — that's failure.

Also: the lock file was part of the problem. There was one lock file (`runs/active.lock`) blocking ALL experiments when any experiment was running. That's wrong — there should be two types: a large-run lock and a small-ablation lock. Large runs block other large runs. Small ablations block other small ablations. But small ablations can coexist with a large run. Fixed the code and the docs to reflect this.
