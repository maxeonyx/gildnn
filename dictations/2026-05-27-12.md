# Dictation 2026-05-27-12

Accumulation-based rate thresholds. On the first turn, the first token provides a lot of info — the blocks would only output their priors up till then. But on turn two the next token might be super predictable, so higher blocks may not need to run.

The stream accumulates information over time. When the stream already contains a confident prediction (because prior turns have built it up), and the new actual is close to what was predicted, the surprise is small. Higher blocks don't need to update — they can skip. The rate at which blocks run should be gated by how much new information is arriving, which is exactly the surprise/mismatch signal.

This connects multi-rate to predictive processing naturally: blocks run when they're surprised, not on a fixed schedule.
