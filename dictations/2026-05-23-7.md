## Architecture correction: only block 0 gets the token embedding

Oh, all blocks receive the token embedding? That's not at all what I intended. I intended only one block to receive the token embedding. The other ones would simply be farther away from the input. The entire point is that higher blocks get information delayed by propagation time.

This changes the interpretation of the "lateral gradients don't matter" result — of course they don't matter if every block already has direct access to the tokens. In my intended architecture, deeper blocks *depend* on lateral propagation for their input.

## Local learning signal (open question)

The question of what local learning signal to use for interior blocks remains open. We discussed an attention-based "usefulness" signal but on further analysis it has serious problems (salience learning rather than content learning, grounding decay with depth, chicken-and-egg on what "useful" means). More promising directions are closer to predictive coding or target propagation — something where the local objective is grounded in real prediction error, not just social selection.

The bidirectional output structure (one output toward input, one away from input) may still be useful regardless of what the local loss turns out to be.
