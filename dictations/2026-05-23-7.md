## Architecture correction: only block 0 gets the token embedding

Oh, all blocks receive the token embedding? That's not at all what I intended. I intended only one block to receive the token embedding. The other ones would simply be farther away from the input. The entire point is that higher blocks get information delayed by propagation time.

This changes the interpretation of the "lateral gradients don't matter" result — of course they don't matter if every block already has direct access to the tokens. In my intended architecture, deeper blocks *depend* on lateral propagation for their input.

## Bidirectional outputs with attention-based usefulness

I've got a slightly interesting idea here. Let's say that for each block there is an input attention and then there are two outputs, one going towards the input and one going away from the input. Then the block's goal is to produce outputs that are deemed useful by the attention of the blocks on either side of it.

So the learning signal is: "did my neighbor attend to what I produced?" If a block's output gets high attention weight from its neighbors, it's producing useful representations. If not, it needs to change. This is a local learning signal — each block only needs to know whether its immediate neighbors found its output useful.
