# Dictation 2026-05-21-4

Mix-add is not a fix for training stability. It's only a fix for having to tune the residual backbone. The correct optimizer and probably at least one norm somewhere might be needed for training stability. You can still get exploding activations with mix-add, as it doesn't do any activation scaling of any kind.

I think it's kind of the optimizer's job to do this, in my opinion. Or the optimizer plus some kind of per-layer method. Like there should in theory be ways to invariantly scale weights across the network so that the activations don't explode.

I was thinking about this — maybe we should be using the Muon optimizer, because I'm pretty sure that tries to make all of the weight matrices orthogonal. Am I right? Orthogonal weight matrices would make a lot of sense, then you really shouldn't get exploding activations. Also orthogonal embeddings too.
