# Don't rely on torch.compile — vectorize the blocks

Don't pray for divine intervention from torch.compile. Make the blocks work independently. They're all copies of each other — so you can batch all the blocks into a single tensor operation. Run all levels in parallel as a batched matmul, not a sequential Python loop. The blocks are weight-shared, so it's literally the same weights applied to different inputs. That's just a batch dimension. It should be fine.
