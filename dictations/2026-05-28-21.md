# Performance: the whole thing stays on GPU

The point is there is a recurrence structure. Therefore it should be possible to keep things sitting in the GPU and not going back and forth between the CPU. The whole thing is a GPU programme, that's how I imagine it. The only thing feeding in is the new tokens. And the only thing feeding out is like the gradients and the updates. But we could probably batch them. The gradients have to get accumulated somehow. The whole thing should stay on the GPU.
