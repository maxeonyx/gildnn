# Background experiment execution — don't block the agent on training runs

Experiments are currently blocking progress significantly. Like a three-hour experiment wastes a whole heap of time that we could be using for improving the library, doing tiny experiments, improving the process, doing research, these kinds of things — anything that doesn't use the GPU in a major fashion.

Ideally we would be launching experiments in the background somehow, tracking them and monitoring them, but continuing. Don't run experiments just directly with the PowerShell tool. Run them with some kind of background start process or something like that that will immediately return but give you a process ID to monitor later.

## Subagent instruction requirement

The subagent needs to be explicitly told this or it will do the default thing, which is to block on the experiment. Instead what it should do is start the experiment running — if it's expected to run for more than say five minutes, it should report back: "I started the experiment, you're free to go out and do other things and resume me when you're ready to check on the experiment."

The subagent needs to be specifically told to start the experiment and then stop and return. And it needs to be explicitly told to say this — something like: "I have started the experiment and I'm stopping here as requested. Please resume me when you're ready to check on the experiment."
