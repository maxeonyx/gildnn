Multiple CE heads (per-band CE, where each band predicts tokens at a different horizon) is an unprincipled hack. I've asked not to do this many times. We need local methods. The only CE head should be on band 0, or wherever the output is. The other bands need to learn from local objectives only — predicting their neighbors, or something else that doesn't require a global token-prediction signal.

The exception would be if someone can convince me that token prediction at every level is biologically plausible. I'm open to that argument but I haven't heard it yet. Until then, one CE head, local learning for everything else.

Return to the original dictations and understand what I actually want. The architecture is a cellular automaton with local learning. "Local" means each module learns from its own neighborhood, not from a global objective broadcast to every level.
