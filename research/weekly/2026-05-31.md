# Project summary — The architecture is built. The local learning rule is not.

The project ran 10 days (May 20–31). It started from "does any piece of this work?" and ended at a precise open question: what local neighborhood objective creates multi-timescale representations that help token prediction, without broadcasting a global objective to every module?

The architecture is built and each piece has been tested. But local learning — the core thesis — remains unsolved. Two boundary conditions bracket the missing piece.

## The local learning saga

This is the core story. Each attempt narrowed what the local objective must be.

**InfoNCE** — genuinely local, each module predicts its neighbors' representations contrastively. Architecturally correct per Max's vision. But its gradient is orthogonal to token prediction:

```
Gradient cosine between CE and InfoNCE: 0.013 — effectively orthogonal.
```

The lag probe after 5000 steps confirms the failure — only band 0 learned anything token-useful:

```
Lag probe (InfoNCE, step 5000):
       lag=  1 lag=  2 lag=  4 lag=  8 lag= 16 lag= 32 lag= 64
band0:  33.5%  23.5%  19.6%  16.0%  13.6%  13.6%  13.8%
band1:  17.4%  16.1%  16.3%  15.4%  14.9%  14.4%  15.0%
band2:  14.6%  14.8%  15.3%  14.7%  14.3%  15.0%  15.5%  (random: ~14-15%)
band5:  14.6%  15.8%  12.9%  13.2%  13.1%  12.4%  12.4%
```

InfoNCE trained the local predictors (local loss went down) without forcing representations to encode task-relevant temporal information. The loss is local and healthy — just orthogonal to what matters.

**Multi-scale input, cross-band negatives, temporal targets** — all null. The problem is not the input encoding or diversity. It's the prediction target itself.

**Gradient audit** — even if global CE could help, it can't reach higher bands. The local loss drowns it:

```
After 500 steps of attention readout:
         CE grad    Local grad    Ratio
band 0      0.63         0.00        —
band 1      0.27        11.71       44×
band 2      0.29        10.42       36×
band 3-7:  0.26-0.30    3-11       18-44×
```

**Per-band CE** — each band predicts the token at horizon min(2^b, 64). All 8 bands below entropy within 30 steps:

```
Per-band CE (step 30):
b0: 3.24  (horizon +1)     b4: 3.82  (horizon +16)
b1: 3.49  (horizon +2)     b5: 4.11  (horizon +32)
b2: 3.64  (horizon +4)     b6: 4.05  (horizon +64)
b3: 3.76  (horizon +8)     b7: 4.23  (horizon +64)
Entropy baseline: 4.17
```

Existence proof that the architecture CAN specialize. But [dictation 2026-05-31-01](../../dictations/2026-05-31-01.md) rejects per-band CE: it broadcasts a global token-prediction objective to every level. One CE head on band 0, local learning for everything else — that's the design constraint.

**Fixed readout can't exploit specialization** — band utility test with per-band CE checkpoint: band 0 alone gives CE 2.61, adding any other band makes it worse (3.09–3.49). A full-stack experiment (per-band CE + learned attention readout, 2000 steps) confirmed this:

```
Full-stack attention readout (step 2000): CE = 3.03
Band 0 alone:                             CE = 2.46
```

Even with 2000 gradient steps training an attention head over all 192 module states, the readout could not extract useful next-token information from the per-band representations. The readout problem is real regardless of which local objective creates the specialization.

## The bracketing result

InfoNCE and per-band CE bracket the missing piece from opposite sides:

- **InfoNCE:** local, architecturally correct — but orthogonal to the task. Modules learn to predict neighbors without encoding temporal information useful for token prediction.
- **Per-band CE:** task-aligned, rapid specialization — but not local. A global objective broadcast to every level.

Together they define the question precisely: what local neighborhood objective is both genuinely local (no token prediction signal broadcast) AND task-aligned enough to create representations that differ across timescales?

---

## Theory exploration: the best hypothesis

After surveying the design space (see [research/questions/local-objectives/](../questions/local-objectives/README.md)), one approach stands out:

**Hierarchical future-state prediction through noise:** band _k_ predicts a summary of band _k-1_'s state at `t + rate(k)`. Only band 0 has CE. The noisy laterals provide the information bottleneck that prevents trivial copying.

How it differs from what was tried:
- vs InfoNCE: predicts the **future**, not identity-matches the present
- vs raw MSE: noise forces compression (can't copy through noisy channel)
- vs per-band CE: target is neighbor's output (local), not token stream (global)

Task alignment propagates upward: band 0's features encode tokens → band 1 predicts band 0's dynamics → must understand token dynamics → band 2 predicts band 1's dynamics → higher-order structure emerges.

This is not validated. It's the strongest hypothesis to test next. Key risks: MSE on projected states might still be too high-dimensional; alignment might not propagate in practice; warm-up may be needed.

## What a future session picks up

**First experiment:** 30-second sanity check of hierarchical future-state prediction. 2 bands only. Band 0 has CE. Band 1 predicts a projection of band 0's output at `t+2`. If band 1's loss decreases AND band 0's CE improves, the mechanism creates useful upward pressure. Full design in [research/questions/local-objectives/](../questions/local-objectives/README.md).

**What's built:**
- `core/automaton_graph.py` — 192-module 2D graph, multi-rate bands, detached laterals, refractory messaging
- `core/triton_forward.py` — fused forward kernel (forward only)
- Diagnostics: lag probe, band similarity, band utility, gradient audit
- Training infrastructure: systemd services, checkpointing, streaming TBPTT

**Key constraint for the local objective:** neighborhood-only signal, must create representations that differ across timescales, must produce gradients that point roughly toward token prediction utility.

---

## Honest assessment

The architectural pieces work individually. Several are clean results — detached laterals beating global backprop, multi-rate as a time/quality tradeoff, width scaling outperforming depth. The 192-module graph runs and learns.

But the central thesis — local learning creating cooperating multi-timescale representations — is not validated. InfoNCE is orthogonal to the task. Per-band CE is architecturally wrong. The right local signal is an open question, and Max has correctly identified that answering it needs theory first, not more ablations.

The project narrowed the question from "does any of this work?" to "what should the local signal be?" — a sharper question, with an architecture ready to test whatever answer comes next.
