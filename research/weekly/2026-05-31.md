# Project summary — Weight tying works. Local learning does not (yet).

The project ran 10 days (May 20–31). It produced one clear positive and one clear negative: weight tying (the fundamental thesis) is validated, while local learning (the training mechanism) remains unsolved for the tested objective family.

## The local learning saga

This is the core story. Each attempt narrowed what the local objective must be.

**InfoNCE** — genuinely local, each module predicts its neighbors' representations contrastively. Architecturally correct per Max's vision. But its gradient is orthogonal to token prediction:

```
Gradient cosine between CE and InfoNCE: 0.013 — effectively orthogonal.
```

The lag probe after 5000 steps confirms the failure — only band 0 learned anything token-useful:

```
Lag probe (InfoNCE, step 5000):
       lag=  1 lag=  2 lag=  4 lag=  8 lag= 16 lag= 32 lag= 64
band0:  33.5%  23.5%  19.6%  16.0%  13.6%  13.6%  13.8%
band1:  17.4%  16.1%  16.3%  15.4%  14.9%  14.4%  15.0%
band2:  14.6%  14.8%  15.3%  14.7%  14.3%  15.0%  15.5%  (random: ~14-15%)
band5:  14.6%  15.8%  12.9%  13.2%  13.1%  12.4%  12.4%
```

InfoNCE trained the local predictors (local loss went down) without forcing representations to encode task-relevant temporal information. The loss is local and healthy — just orthogonal to what matters.

**Multi-scale input, cross-band negatives, temporal targets** — all null. The problem is not the input encoding or diversity. It's the prediction target itself.

**Gradient audit** — even if global CE could help, it can't reach higher bands. The local loss drowns it:

```
After 500 steps of attention readout:
         CE grad    Local grad    Ratio
band 0      0.63         0.00        —
band 1      0.27        11.71       44×
band 2      0.29        10.42       36×
band 3-7:  0.26-0.30    3-11       18-44×
```

**Per-band CE** — each band predicts the token at horizon min(2^b, 64). All 8 bands below entropy within 30 steps:

```
Per-band CE (step 30):
b0: 3.24  (horizon +1)     b4: 3.82  (horizon +16)
b1: 3.49  (horizon +2)     b5: 4.11  (horizon +32)
b2: 3.64  (horizon +4)     b6: 4.05  (horizon +64)
b3: 3.76  (horizon +8)     b7: 4.23  (horizon +64)
Entropy baseline: 4.17
```

Existence proof that the architecture CAN specialize. But [dictation 2026-05-31-01](../../dictations/2026-05-31-01.md) rejects per-band CE: it broadcasts a global token-prediction objective to every level. One CE head on band 0, local learning for everything else — that's the design constraint.

**Fixed readout can't exploit specialization** — band utility test with per-band CE checkpoint: band 0 alone gives CE 2.61, adding any other band makes it worse (3.09–3.49). A full-stack experiment (per-band CE + learned attention readout, 2000 steps) confirmed this:

```
Full-stack attention readout (step 2000): CE = 3.03
Band 0 alone:                             CE = 2.46
```

Even with 2000 gradient steps training an attention head over all 192 module states, the readout could not extract useful next-token information from the per-band representations. The readout problem is real regardless of which local objective creates the specialization.

---

## The bracketing result

InfoNCE and per-band CE bracket the missing piece from opposite sides:

- **InfoNCE:** local, architecturally correct — but orthogonal to the task. Modules learn to predict neighbors without encoding temporal information useful for token prediction.
- **Per-band CE:** task-aligned, rapid specialization — but not local. A global objective broadcast to every level.

Together they define the question precisely: what local neighborhood objective is both genuinely local (no token prediction signal broadcast) AND task-aligned enough to create representations that differ across timescales?

Max's directive ([dictation 2026-05-31-04](../../dictations/2026-05-31-04.md)): explore many local objectives, don't settle on one.

**Hierarchical targets** (`--hierarchical-targets`): band _k_ predicts the mean state of band _k-1_.

**CORRECTION:** The earlier "CE 2.67 — best purely-local result" was mislabeled. That run used the standard band-0 CE readout (CE gradient into band 0), making it a hybrid. The 2.67 is approximately the same as the control (2.70) — hierarchical targets on bands 1-7 don't measurably help band 0's CE.

The truly purely-local version (detached attention readout, no CE gradient to any band) gives **CE 3.28 at step 100, worsening to 3.52 at step 1000**. Band 0 is completely untrained in this config. Local prediction learning actively destroys incidental token information.

## What a future session picks up

**The gating question is answered: YES, weight tying works.** The afternoon's experiments (see daily 2026-05-31) tested the Pathway 1 thesis cleanly:

| Config | Params | Val CE | FLOPs relative |
|--------|--------|--------|------|
| Untied d=128, 8 layers | 1.6M | 1.87 | 1× |
| Tied d=256, 2 iterations | 854K | 1.85 | 1× (same!) |
| Tied d=256, 4 iterations | 854K | 1.80 | 2× |
| Tied d=256, 8 iterations | 854K | 1.79 | 4× |
| Tied d=256, 16 iterations | 854K | 1.77 | 8× |
| Tied d=256, 32 iterations | 854K | 1.74 | 16× |

**Key findings:**
- Width compensates for weight tying: tied d=256 N=2 beats untied d=128 N=8 at **same FLOPs** and **half the params**
- Iteration scaling is logarithmic: each doubling gives ~0.02-0.04 nats improvement
- Stable through 32 iterations without gradient explosion
- Per-token analysis: mean optimal N=5.1, 95th percentile=8. Moderate dynamic depth headroom.
- **Dynamic depth demonstrated:** CE-based early exit saves 43% of compute with only +0.045 nats loss. At small thresholds, early exit actually IMPROVES val CE (regularization effect). Entropy-based exit (deployable, no ground truth) also works but is noisier.
- **Context length robustness (ctx=256):** Per-param advantage holds (tied 1.841 beats untied 1.905, half the params). FLOP-matched advantage (tied N=2 vs untied N=8) breaks — longer context needs more iterations.
- **Iteration scaling steeper at longer context:** At ctx=128, gains taper quickly (N4→N8: 0.014 nats). At ctx=256, gains stay high (N4→N8: 0.066 nats). Dynamic depth decisions are more impactful at longer context.

This validates the project's most fundamental hypothesis: a wider block iterated N times can match or beat N distinct narrower layers, with the advantage of parameter efficiency and dynamic depth potential.

**Learned halting predictor (bridges oracle→deployable gap):**

A frozen-model regression probe (tiny MLP: hidden_state + scalar features → predicted remaining gain) achieves 85% oracle efficiency at practical operating points:

```
Method                    | Mean Iters | Compute Savings | CE Overhead
Full depth (N=8)          |       8.00 |           0.0%  |    +0.000
Learned (hidden) thr=0.05 |       6.12 |          23.5%  |    -0.000
Learned (hidden) thr=0.10 |       5.53 |          30.9%  |    +0.023
Oracle CE-based thr=0.10  |       4.58 |          42.7%  |    +0.046
Entropy heuristic (best)  |       7.32 |           8.5%  |    +0.025
```

Hidden state Pearson r=0.53 for predicting remaining gain; entropy alone r=0.42. The model's internal state encodes *which tokens will benefit from more iterations* — this is deployable information.

This holds at longer context too. At ctx=256, the hidden-state predictor still reaches r=0.51 and gives a practical operating point of **22.1%** compute savings at only **+0.006** nats (full-depth val CE baseline **1.840**). The interesting change is that the **oracle criterion gets worse**: at ctx=128, oracle early exit helped by regularizing an overfit model, but at ctx=256 the smallest oracle threshold is already **+0.072** nats. The learned predictor still gets **negative** overhead at small thresholds and even beats oracle at matched overhead for larger thresholds, which implies that predicting **total remaining gain** is a better stopping rule than thresholding the **next-step gain** itself.

**The 192-module graph's failure (CE 2.69) is NOT caused by weight tying.** It's caused by the communication structure (stale detached laterals, multi-rate, 2D topology) and/or the narrow per-module width (d_stream=96). The tied transformer at d=256 works fine.

## Honest assessment

The project produced one clear positive result and one clear negative result.

**Positive (Pathway 1):** Weight tying works. A wider tied model (d=256, 854K params, same block iterated 2-32 times) matches or beats an untied model (d=128, 1.6M params, 8 distinct layers) at equal FLOPs. Stable through 32 iterations. Logarithmic scaling in N. Per-token analysis shows moderate dynamic depth headroom (mean optimal N=5). This validates the fundamental thesis: width + iteration can substitute for depth at lower parameter cost.

**Positive (Pathway 5):** Dynamic depth is practical. A learned halting predictor (frozen-model probe, tiny MLP on hidden state) achieves 23.5% compute savings at zero quality cost, or 30.9% savings at +0.023 nats (85% oracle efficiency). Hidden state strongly predicts which tokens benefit from more iterations (Pearson r=0.53). This bridges the oracle→deployable gap demonstrated earlier.

**Negative (Pathway 3):** The tested local objectives (predict neighbors/lower-bands/inputs) are structurally misaligned with token prediction on the 192-module graph with detached laterals. All tested purely-local objectives produce CE 3.2-3.5 vs control 2.70. CE worsens over training as local prediction improves. The gradient cosine between local and CE objectives is 0.013 (orthogonal).

**The gap between the two results:** The positive weight-tying result uses a single-stream transformer with global CE training — no lateral communication, no multi-module structure, no local learning. The 192-module graph's failure (CE 2.69 vs GRU 1.35) is due to the communication/topology structure, not weight tying. The path forward is: either fix the multi-module communication (so it doesn't destroy quality), or use the simpler tied transformer directly (which already works).

**What this does NOT show:** that local learning is impossible, that the 192-module graph can't be made competitive (it was never tested without stale detached laterals), or that dynamic depth delivers practical wall-clock speedups at scale (it was demonstrated on a frozen probe — joint training and actual variable-computation inference remain untested).

The project's honest output: a validated weight-tying thesis, a working learned halting predictor (Pathway 5), a well-characterized negative result for one family of local objectives, a working codebase, and a theoretical framework for future work.
