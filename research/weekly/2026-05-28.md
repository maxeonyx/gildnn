Separate optimizers + fixed embeddings eliminated gradient interference entirely.

**"Does W₂² loss work for distribution prediction?"** — Yes. Numerically identical to MSE on (μ,σ). Converges past copy baseline. No exotic optimization surface ([05_w2_learning_convergence.py](../../experiments/predictive_processing/05_w2_learning_convergence.py)).

None of these are blockers anymore. If we ran the full architecture with broken combining or blocks that needed state, the result would be uninterpretable. Now we know the pieces work. The only remaining question is whether the whole thing works together at scale.

## What changed understanding this week

**Local learning is strictly superior to global backprop.** Not a compromise for parallelism — actually better. Block 0 at 3.85 nats (detached laterals) vs 4.07 (global), gap growing monotonically. The gradient interference from higher blocks is real and cumulative.

**Combining adds real signal.** Stream combining with real Block 1 predictions: 42% gain over copy. Passthrough (no combining): 37%. Random predictions: 35%. The 5pp gap between combined and passthrough is the mechanism working — modest but consistent across 800 steps.

**Blocks are stateless.** Horizon sweep H=1 and H=2 both null. Noise validation: high noise pushes both GRU and feedforward to identical "predict the mean" behavior. No tested condition produces a recurrence advantage. The frozen Block 0 representation is approximately history-sufficient.

**Tempered PoE combining is validated.** Piece test 06: process noise, calibration, variance handling, graceful degradation. 26/26 property checks pass ([06_bayesian_combining.py](../../experiments/predictive_processing/06_bayesian_combining.py)).

**W₂² = MSE on (μ,σ).** Not metaphorically — numerically identical (max diff 8.3e-17). Standard Euclidean loss. Converges past copy baseline cleanly.

## The recurrence nulls confirm the design

H=1 null, H=2 null (gap −0.000024), noise validation null. Every condition that should have shown a recurrence advantage didn't. This is the right answer — if Block 0's current state already encodes everything relevant about the past, blocks don't need internal state. They're stateless transforms. The full model creates temporal integration through the grid structure (information bouncing between many blocks over many timesteps), not through per-block hidden state.
