# 2026-05-26 — Local lateral communication works on real language

## The headline

A locally-trained interior block **improves** a short-context output block on character-level language modeling. The key variable is **local objective quality** — the objective must target the *exported* representation (last-position hidden state), not all positions.

Staging (training blocks sequentially) is NOT required. Co-training with gradient isolation works slightly better.

## Afternoon: synthetic validation

Split-input test: 100% accuracy when blocks see different inputs. Proves lateral mechanism works with information asymmetry.

Context-asymmetry (co-trained): 12% (chance). Co-training fails with a trivial reconstruction objective on SYNTHETIC random tokens — but the reason turns out to be the objective, not the co-training itself.

Context-asymmetry (staged): 100%. Hard staging rescues the weak reconstruction objective by freezing the representation before lateral learns.

**Intermediate (wrong) conclusion:** "staged training is required." This was overfit to the synthetic task.

## Evening: real language modeling — the correct answer

Experiment: `runs/staged_char_lm.py` on TinyShakespeare (80K train chars).
- Block 0: 8-char context, CE next-char prediction
- Block 1: 64-char context, local objective only
- Lateral: block 1's last-position state → learned projection → additive to block 0 (scale=0.2, gradient detached from block 1)

**Iteration 1 — reconstruction at all positions (FAILS):**

| Condition | Val loss | Δ |
|---|---|---|
| block0_alone | 1.8736 | — |
| staged_lateral | 1.8875 | +0.014 |
| cotrained_lateral | 1.8644 | -0.009 |

Diagnosis: block 1's reconstruction converges to near-zero (0.0002) because self-attention + positional embeddings trivially copies each input token. The last-position state encodes nothing useful about long-range context.

**Iteration 2 — last-position-only next-char CE (WORKS):**

| Condition | Val loss | Δ |
|---|---|---|
| block0_alone | 1.8736 | — |
| staged_lateral | 1.8606 | **-0.013** |
| cotrained_lateral | 1.8563 | **-0.017** |
| shuffled_staged | 1.8848 | +0.011 |

Shuffled control confirms content matters (+0.011 worse than baseline). Real lateral content helps (-0.017 better).

## Revised requirements for working lateral communication

1. **Information asymmetry** — block 1 must have info block 0 lacks (longer context)
2. **Last-position pressure** — local objective must target the exact vector that gets exported
3. **Gradient isolation** — lateral detached; no task gradient flows into interior blocks

## Evening: multi-block experiments (`runs/multi_block_lm.py`)

Tested whether two interior blocks (ctx=32, ctx=128) are complementary or redundant.

**Initial finding (800 steps) — blocks appear redundant:**

| Condition | val_loss | Δ |
|---|---|---|
| block0_alone (ctx=4) | 1.8561 | — |
| one_block_mid (ctx=32) | 1.8189 | -0.037 |
| one_block_long (ctx=128) | 1.8458 | -0.010 |
| two_blocks (32+128) | 1.8198 | -0.036 |

The long block barely helps. Two blocks ≈ mid block alone. Diagnosis: long block's local CE still high (~1.88) — it hasn't converged on its own local task.

**Capacity ablation:** d_model=128 for long block gives -0.024 (partial improvement). 2 layers gives -0.010 (nothing). Width > depth, but doesn't fully close the gap.

**Pretrain+freeze (4000 steps pretrain, 800 finetune) — blocks become complementary:**

| Condition | val_loss | Δ from 800-step baseline |
|---|---|---|
| one_block_long pretrained | 1.7043 | -0.152 |
| one_block_mid pretrained | 1.6930 | -0.163 |
| two_blocks both pretrained | **1.6567** | **-0.199** |

Pretraining fixes everything: long block helps massively, blocks are complementary (two > either alone). The "redundancy" was entirely a learning dynamics artifact.

**Co-train 4800 steps (final resolution) — no staging needed:**

| Condition | val_loss |
|---|---|
| block0_alone @ 4800 | 1.7115 |
| two_blocks co-trained @ 4800 | **1.6435** |

**Co-training for longer beats pretrain+freeze.** Absolute val_loss: 1.6435 < 1.6567. The system self-organizes given enough training. No staging, no freezing, no tricks needed.

## Late evening: New architecture from dictation (2026-05-26-5)

Max described the architecture he actually wants: weight-tied readout (no output projection), addition as the inter-block combination mechanism (IS Bayesian product in log space), and normalization to unit sphere.

Validated piece by piece at tiny scale (`runs/tied_readout_lm.py`):

### A0: Weight-tied readout

Replace `nn.Linear(d_model, vocab_size)` with `logits = hidden @ embedding.weight.T / temperature`.

| Condition | val_loss |
|---|---|
| block0_alone (tied readout) | 1.7206 |
| block0_alone (old linear head) | 1.7115 |

Works. Essentially no difference from the old readout. One shared embedding serves as both input and output.

### A1: Addition-based combination

Replace learned `lateral_proj` with direct addition of hidden states. First attempt (no normalization, no scale): catastrophic (+0.285 worse). Diagnosis: magnitude issue, not architectural failure.

**Scale sweep** (laterals multiplied by scale factor before addition):

| lateral_scale | two_blocks val_loss | Δ from block0_alone |
|---|---|---|
| 0.0 | 1.7171 | ~0 (sanity: no lateral) |
| 0.1 | 1.7110 | -0.010 |
| 0.2 | 1.6915 | -0.029 |
| 0.5 | 1.6792 | **-0.041** |
| 1.0 | 2.0060 | +0.285 (catastrophic) |

With normalized embeddings + outputs + temperature=0.07 (the dictation's "simplest version"):

| Condition | val_loss | Δ |
|---|---|---|
| block0_alone (normalized) | 1.7522 | — |
| two_blocks (normalized, temp=0.07) | **1.6646** | **-0.088** |

**Normalization makes the lateral effect LARGER than the old architecture** (-0.088 vs -0.068 with old learned combiner).

### A2: Embedding-space local loss (rejected)

Cosine: +0.14 worse than CE. L2: +0.05 worse. CE provides richer gradient (pushes away from all wrong tokens). **Keeping CE for local loss.**

### Scale-up (d_model=128, 2 layers, 20K steps)

| Condition | val_loss | wall_s |
|---|---|---|
| block0_alone (normalized, temp=0.10) | 1.6342 | 171s |
| two_blocks (normalized, temp=0.10, scale=0.2) | **1.5893** | 468s |
| Δ | **-0.045** | |

The effect persists at scale. Lateral scale factor (0.2) is needed even with normalization — blocks aren't truly independent predictors (shared embeddings, overlapping input).

## Validated architecture

1. **Shared normalized token embedding** (weight-tied readout)
2. **Normalized block outputs** (L2 norm before combination)
3. **Addition-based laterals** (detached, scaled by 0.2)
4. **CE local loss** (last position, gradient isolation)
5. **Temperature = 0.07–0.10** (controls logit sharpness)
