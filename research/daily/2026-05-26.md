# 2026-05-26 — Staged training works: the architecture needs development phases

## The headline

A locally-trained block CAN help an output block via lateral communication — but only with staged training. Co-training from scratch always fails because the lateral pathway can't learn from an unstable source representation. Train block 1 first (local loss → stable representation), freeze it, then train the lateral projection. Result: 100% accuracy on a task the output block cannot solve alone.

This validates the core mechanism of the multi-timestep architecture. The remaining question: does it work on a real language modeling task (not just synthetic delay-copy)?

## Why composition fails: information asymmetry

Split-input test (`runs/split_input_test.py`): block 0 sees token A, block 1 sees token B, task requires both. **100% accuracy** with lateral, 12% without. Proves the mechanism works when block 1 has unique information.

Context-asymmetry test (`runs/context_asymmetry_test.py`): block 0 sees 4 tokens, block 1 sees 32 tokens. Task: predict token from 16 steps ago (outside block 0's window). Block 1 oracle: 100%. **Block 0 + lateral: 12% (chance).**

Why: with "predict block 0's state" as the local loss, block 1 learns to be *redundant* with block 0 (even when it has more information). The loss pushes toward imitation, not complementarity. Switching to reconstruction loss (block 1 predicts its own input tokens) doesn't fix it either — because the problem is co-training dynamics, not the loss function.

---

## The fix: staged training

```
Phase 1: Train block 1 alone (reconstruction loss, 300 steps → converges)
Phase 2: Freeze block 1. Train lateral_proj + output_head with CE (200 steps → 100%)
```

Shuffled control: 12.9% (chance). The content of the lateral matters — not just its presence.

The key insight: block 1's representation must STABILIZE before the downstream pathway can learn to decode it. With co-training, lateral_proj is trying to hit a moving target that changes every step as block 1 improves its reconstruction. By staging, the target becomes fixed and trivially learnable.

## What changed in understanding

| Before today | After today |
|---|---|
| "Mixing ratio is the problem" | Mixing ratio matters, but information asymmetry is the prerequisite |
| "Predict block 0's state" is the local loss | "Reconstruct own input" is a better local loss (preserves unique info) |
| Single training phase assumed | Staged training required: develop → connect → fine-tune |
| "Does local loss help?" is one question | It's three questions: does the piece work? do blocks need different info? does co-training work? |

## What's next

The mechanism is validated on synthetic tasks. Bridge to real language modeling:

1. Block 0: short context (4-8 tokens), trained with CE
2. Block 1: long context (32-64 tokens), trained with reconstruction
3. Stage 1: train both independently. Stage 2: connect lateral, fine-tune projection
4. Task: character-level LM (natural language inherently benefits from longer context)

If short-context block 0 + long-context block 1 beats short-context block 0 alone on real text — the architecture is working.

Alternative to hard staging: **curriculum warmup** — lateral_scale ramps from 0 to target over training. More biologically plausible (connections strengthen as representations stabilize).
