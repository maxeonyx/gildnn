# 2026-05-21

The architecture works. "Residual streams across time" — a single residual block reused across timesteps, with causal attention over its own past states — trains and produces language. That's the headline. Everything else today is detail about what makes it work and what doesn't yet discriminate.

## Residual stream across time: viable, norm-dependent

Three variants of the same core idea at d_model=192, 50K chars TinyShakespeare, 3 epochs. One residual block, temporal attention window k=4:

```json
// experiments/residual_stream_time/artifacts/scaleup-192/training_history.json (no norm)
{"epoch": 3, "val_loss": 3.28991, "val_accuracy": 0.152073}

// experiments/residual_stream_time/artifacts/scaleup-192-timestep-norm/training_history.json (LayerNorm)
{"epoch": 3, "val_loss": 1.787978, "val_accuracy": 0.470008}

// experiments/residual_stream_time_mixadd/artifacts/scaleup-192/training_history.json (mix-add, no LN)
{"epoch": 3, "val_loss": 1.790906, "val_accuracy": 0.46875}
```

| Variant | Val loss | Params | Stream RMS | What happens |
|---------|----------|--------|-----------|--------------|
| [No norm control](../../experiments/residual_stream_time/artifacts/scaleup-192/) | 3.29 | 480K | 1555 | Broken — stream explodes, attention uniform |
| [Temporal pre-norm (LayerNorm)](../../experiments/residual_stream_time/artifacts/scaleup-192-timestep-norm/) | 1.788 | 481K | 3.33 | Recognizable English |
| [Learned mix-add](../../experiments/residual_stream_time_mixadd/artifacts/scaleup-192/) | 1.791 | 479K | 1.01 | Matches LN quality, no normalization layers |

For reference: transformer anchor 1.63 at 186K params (from yesterday's standardized runs). The residual-stream-time models are ~2.6× larger but undertrained — only 3 epochs on 50K chars, loss still declining at termination.

**Temporal norm management is non-negotiable.** Without it the residual stream magnitude grows without bound across timesteps. At RMS 1555, attention scores are saturated and the model outputs near-uniform distributions. With either LayerNorm or mix-add keeping the stream bounded, the same architecture drops 1.5 nats.

**Mix-add matches LayerNorm with no normalization layers.** The mechanism is a learned scalar convex combination at each injection point: `stream = α·stream + (1-α)·new_value`. Learned coefficients after training (from [model_summary.json](../../experiments/residual_stream_time_mixadd/artifacts/scaleup-192/model_summary.json)): token entry α≈0.49, block update α≈0.88, temporal update α≈0.93. The model learns to weight the existing stream heavily at the temporal injection point — cautious about overwriting with temporal context.

Sample output (mix-add, epoch 3):

```text
First Citizen:
Before we proceed any further, hear me speak.

All:
No me the wart he hear the here he hears the wart he hear...
```

Repetitive, but structurally correct (speaker tags, newlines, word boundaries). This is 3 epochs on 50K characters — far from converged.

## Diagonal coupling: inconclusive

Max's "main thing I want to explore" — block i at time T feeds block i+1 at time T+1, creating a diagonal information path through depth×time. Tested with 2 blocks:

```json
// experiments/residual_stream_time_diagonal/artifacts/scaleup-192/model_summary.json
{"parameter_count": 777275, "num_blocks": 2}

// training_history.json
{"epoch": 3, "val_loss": 1.787626, "val_accuracy": 0.476852}
```

| Model | Params | Val loss |
|-------|--------|----------|
| [Single block (LN)](../../experiments/residual_stream_time/artifacts/scaleup-192-timestep-norm/) | 481K | 1.788 |
| [Diagonal 2-block](../../experiments/residual_stream_time_diagonal/artifacts/scaleup-192/) | 777K | 1.788 |

Identical val loss at 1.6× the parameters. This is not a negative result — it's inconclusive. Possible explanations: the scale is too small for depth routing to matter, the training budget is too short to discriminate, or 2 blocks isn't enough to exploit diagonal coupling. The important thing is that diagonal coupling doesn't *hurt*, so it remains a live hypothesis at larger scale.

## What changed in understanding

The architecture IS viable. Yesterday's narrative ended with "the direction is crystallizing: RNN-based architecture with async shared-memory execution model." Today that direction got its first concrete instantiation and it works. The residual-stream-across-time framing is more specific than "RNN + attention over history" — it's literally one transformer block that persists its residual state and attends causally over its own past.

The critical insight: norm management is the entire difference between "works" and "doesn't work at all." Not a tuning knob — a binary gate. And mix-add (Max's preferred approach) solves it without introducing normalization layers.

## What's not established

- Whether the val loss gap to the transformer (1.79 vs 1.63) closes with more training. The model is undertrained.
- Whether diagonal coupling helps at larger scale or with more blocks.
- Whether the ~10× training slowdown (sequential timestep dependency) is inherent or can be amortized.
- Parameter efficiency — the model uses 2.6× more params than the transformer anchor for worse loss. Is that the architecture or the training budget?

## Next discriminating steps

1. Longer training run — more data, more epochs — to see if the gap to transformer closes. This separates "undertrained" from "architecturally limited."
2. Mix-add as default in all future experiments (LayerNorm is now the control, not the default).
3. Diagonal coupling at 4+ blocks or larger d_model to give it room to discriminate.
