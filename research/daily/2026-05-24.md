# 2026-05-24 — CE shaping is load-bearing (strict-local collapses)

## The discriminating result

Strip task gradient from the feedback path and the system dies. D_strict_local (same architecture as C_closed_loop, but `feedback.detach()` so CE can't reach block 1) collapsed to a degenerate constant predictor:

| Variant | Mean val_loss | Δ vs A_single |
|---------|--------------|---------------|
| A_single (baseline) | 1.670 | — |
| C_closed_loop | 1.665 | -0.006 |
| B_spectator | 1.677 | +0.006 |
| **D_strict_local** | **3.047** | **+1.377** |

D didn't collapse immediately. The trajectory tells the story:

1. **Steps 1–2K:** D was *better* than A. Early predictions are useful regardless of CE alignment.
2. **Steps 3–13K:** D much worse but slowly improving. Predictions drift from task-relevance; co-adaptation sets in.
3. **Steps 14–20K:** Collapse. pred_loss → 0, accuracy frozen at 0.19, gain → -0.17.

Root cause: full-state cosine prediction treats all hidden dimensions equally. Block 1 learns to predict whatever's easiest (average patterns). Block 0 co-adapts to depend on those predictions. When they drift further from task-relevance, block 0 can't recover — the dependency is locked in. Classic co-adaptation trap.

This settles the question from [dictation 2026-05-23-5](../../dictations/2026-05-23-5.md): "It doesn't have to be totally local. We can be using backpropagation through a local neighborhood of blocks." The semi-local result IS neighborhood-local backprop. CE flowing through the interface is what keeps predictions task-aligned. It's legitimate for parallelism goals — each block pair forms an independent neighborhood.

## V3 closed-loop: mechanism works, benefit tiny

Averaged over 2 seeds (42, 43):

| Variant | val_loss | Δ vs A |
|---------|----------|--------|
| A_single | 1.670 | — |
| C_closed_loop | 1.665 | -0.006 |
| B_spectator | 1.677 | +0.006 |

Per-seed detail:

| Seed | C - A |
|------|-------|
| 42 | -0.009 |
| 43 | -0.003 |

Honest assessment: barely past the -0.005 preregistered threshold. n=2 with seed disagreement. C has 14% more parameters than A (the predictor head). Not statistically convincing as a performance claim.

But that's not the point. The mechanism metrics are what matter:

| Metric | Value | Meaning |
|--------|-------|---------|
| gain | -0.065 to -0.071 | Negative = subtract prediction, process residual |
| pred_loss | ~0.29 | Non-trivial predictions (not collapsed) |
| ablation gap | +0.22 nats | Removing predictions mid-eval hurts significantly |

The gain went negative spontaneously from zero initialization. The model discovered predictive coding on its own: "subtract what I expect, process the surprise." This is the first time any upper-block mechanism hasn't collapsed on the corrected architecture. B (spectator) hurts, confirming that closed-loop feedback specifically — not just extra parameters — is what differentiates block 1's contribution.

---

## What changed in understanding

1. **Full-state prediction as a local objective is dead.** It selects for easy patterns, not task-relevant ones. The co-adaptation → collapse trajectory is now characterized.
2. **Semi-local is the minimum viable locality.** CE must flow through at least the interface between blocks. This is still local in the sense that matters for parallelism (bounded communication neighborhood).
3. **Predictive coding emerges from the architecture.** Negative gain is not something we designed in — it's what gradient descent finds when given a prediction signal and a subtract-or-add choice.

---

## Paths forward

Three options, in order of risk:

1. **Scale semi-local to N=3 blocks.** Safest. Tests whether neighborhood-local extends. Each adjacent pair forms an independent training neighborhood. If it works, parallelism scales with N.

2. **Task-grounded prediction target.** Replace full-state cosine with something CE-relevant by construction: local LM loss, bottleneck latent trained against CE, or synthetic gradients. Attacks the root cause (target doesn't select for task-relevance) rather than patching the symptom.

3. **Per-dimension gate.** Replace scalar gain with a zero-init vector gate. Lets CE suppress nuisance dimensions. Protector, not solution — worth combining with (1) or (2).

The next discriminating experiment: N=3 semi-local. If it works, we have a scalable architecture. If it doesn't, the neighborhood communication pattern breaks down past 2 blocks and we need path 2.
