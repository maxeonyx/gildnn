# 2026-05-28 — Recurrence null confirms stateless design. Build the real thing.

## Why aren't we running the full architecture?

As of today, we can. The back-chain of blockers has collapsed:

1. **Does prediction learning work?** Yes — W₂² converges cleanly, gradient descent on distributions is standard Euclidean MSE on (μ,σ). Validated [05_w2_learning_convergence.py](../../experiments/predictive_processing/05_w2_learning_convergence.py).

2. **Does combining work?** Yes — real predictions add signal beyond raw passthrough:

| Condition | Eval MSE | Copy baseline | Gain over copy |
|---|---|---|---|
| Combined (real B1 predictions) | 0.00161 | 0.00278 | 42.0% |
| Passthrough (raw Block 0) | 0.00306 | 0.00485 | 36.9% |
| Random (noise combined) | 0.00521 | 0.00804 | 35.2% |

From [report.json](../../experiments/tinyshakespeare/artifacts/stream_combining/report.json). Combined > passthrough > random. The 5pp gap between combined and passthrough is modest but consistent across 800 training steps. One seed — provisional, but the ordering is clean.

3. **Should blocks have internal state?** No. The horizon sweep at H=1 and H=2 both show recurrence is a null: recurrent eval 0.003912 vs no-recurrence 0.003887 at H=2 (gap −0.000024). A static feedforward transform matches or beats a GRU. [Horizon sweep report](../../research/questions/horizon-sweep/README.md).

4. **Does noise force recurrence?** No — noise increases prediction advantage over copy (32%→94% at high σ) but drops recurrence advantage to zero (23%→0.15%). At high noise both GRU and FF converge to "predict the mean" because past noisy observations add nothing. From [07_noise_validation.py](../../experiments/predictive_processing/07_noise_validation.py). Noise alone won't create temporal structure. Multi-rate + noise + many timesteps together likely will — but that requires the full model.

Each of these was a potential blocker. None remain. If we ran the full architecture tomorrow with broken combining or blocks that needed state, the result would be uninterpretable. Now we know: combining adds real signal, blocks are stateless, prediction learning converges cleanly.

## The course correction

[Dictation 15](../../dictations/2026-05-28-15.md) makes the architecture explicit. ParallelDiagonalModel — the RNN with GRU carry state — is the wrong model. Max's architecture is a cellular automaton:

- **Nodes** = combining functions
- **Vertical edges** (through time, in-place) = stateless feedforward blocks
- **Lateral edges** (left-right) = propagation + noise

Information bounces between blocks over many timesteps. Higher blocks accumulate context from further back because lower-block outputs merge onto the stream and propagate rightward with delay. Multiple timesteps per token. Noise on laterals creates the information hierarchy.

Two-block toys with seq_len=32 don't test this. The mechanism only activates with many blocks, many timesteps, long sequences.
