# 2026-05-27 — Architecture made correct

## The insight

The model wasn't doing what Max intended. Three hidden couplings — shared embedding gradients, shared optimizer, wrong temperature for fixed embeddings — each made the blocks less independent than designed. Strip all three and block 0's behavior flips from *getting worse* (5.19→9.58 by step 20, gradient interference) to genuinely learning (5.12→3.85 by step 200).

---

## Fix 1: Carry state explosion → per-timestep normalization

**Problem:** Training crashed at step 80 with NaN.

**Root cause:** Lateral accumulation creates effective gain ~1.08 per timestep (0.9 self + 0.18 from lateral_scale=0.2). Over 128 TBPTT steps: 1.08^128 ≈ 17,000. Hidden states explode.

**Fix:** L2-normalize block states at each timestep in [`core/model.py`](../../core/model.py) (commit [`7aee143`](../../core/model.py)).

**Result:** Stable through 200+ steps, no further NaN.

---

## Fix 2: Separate optimizers + fixed embeddings (the big one)

Per dictations [2026-05-27-8](../../dictations/2026-05-27-8.md) and [2026-05-27-9](../../dictations/2026-05-27-9.md).

**Max's intent:** Blocks are separate networks with separate optimizers. The embedding is shared infrastructure, not a learned coupling point.

**Old setup:** One AdamW for all parameters. Shared embedding trained by all blocks' gradients. Block 0's embedding updates pulled toward what helps blocks 1&2, harming block 0.

**Evidence it was wrong:**

```
Old: block 0 loss goes 5.19 → 9.58 by step 20 (worse than random!)
New: block 0 loss goes 5.12 → 3.85 by step 200 (genuine learning)
```

**Fix:** Fixed random unit-vector embeddings (`requires_grad=False`) + one AdamW per block. Commit [`6250ccd`](../../runs/assembled_architecture.py).

---

## Fix 3: Temperature — not what it seemed

**Observation:** Block 0 initializes at CE=5.19. Random uniform over 62 chars = ln(62) = 4.13. Why worse than random?

**Analysis:** With temperature τ=0.07 and random unit embeddings in 96D, dot-product std ≈ 1/√96 ≈ 0.102. Dividing by 0.07 → logit std ≈ 1.46. This creates randomly peaked softmax distributions ("random overconfidence"), pushing expected CE to ~5.19 — exactly matching observation.

**Initial hypothesis:** τ=0.07 is wrong for fixed embeddings; use τ=0.5 (gives init CE≈4.15, near uniform).

**Refuted by experiment:** τ=0.5 gives nicer init but worse final losses (see Temperature Control section below). The "random overconfidence" at τ=0.07 provides better gradient geometry for learning. AdamW normalizes scale; the geometry is what matters.

## Temperature control (τ=0.5 vs τ=0.07)

**Question:** Is τ=0.07 wrong for fixed embeddings? It gives init CE=5.19 (above uniform 4.13).

**Answer: τ=0.07 is correct.** Training with τ=0.5 gives a nicer init (4.15) but worse final losses:

| | Block 0 | Block 1 | Block 2 |
|---|---|---|---|
| τ=0.07, step 200 | 3.85 | 3.29 | 3.27 |
| τ=0.5, step 200 | 3.87 | 3.75 | 3.74 |

Why: AdamW normalizes gradient scale (m/√v), so the 1/τ magnitude factor is irrelevant. What differs is gradient *geometry* — τ=0.07's sharper logits create more contrastive gradient directions. Block 0 reaches the same place either way (~3.85-3.87), but blocks 1&2 are dramatically better with τ=0.07 (3.27 vs 3.74, half a nat!).

Cross-horizon at τ=0.5: flat (no specialization), all rows within 0.01 nats. Confirms blocks at this temperature/scale don't develop horizon-specific representations.

## Local-only vs global-backprop A/B test — THE KEY RESULT

**Question:** How much does detaching laterals cost? Are we leaving performance on the table for the sake of locality?

**Setup:** Identical architecture (3 blocks, rates 1/2/4, τ=0.07, lateral_scale=0.2, separate optimizers). One change: `detach_lateral=True` (A, local) vs `False` (B, global backprop through laterals).

**Final losses (200 steps):**

| | Block 0 | Block 1 | Block 2 |
|---|---|---|---|
| **Local** (detach=True) | **3.851** | 3.286 | 3.269 |
| **Global** (detach=False) | 4.066 | 3.290 | 3.269 |
| Difference | **−0.215** | +0.004 | 0.000 |

**Local learning is strictly better.** Block 0 is 0.215 nats better with local learning. Blocks 1&2 are identical.

**Learning curve comparison:**

| Step | Block 0 (L/G) | Block 1 (L/G) | Block 2 (L/G) |
|---|---|---|---|
| 20 | 5.12 / 5.14 | 3.67 / 3.66 | 3.50 / 3.48 |
| 60 | 4.93 / 5.03 | 3.39 / 3.38 | 3.30 / 3.29 |
| 100 | 4.61 / 4.84 | 3.34 / 3.34 | 3.28 / 3.28 |
| 140 | 4.22 / 4.53 | 3.31 / 3.31 | 3.27 / 3.27 |
| 200 | 3.85 / 4.07 | 3.29 / 3.29 | 3.27 / 3.27 |

The gap grows monotonically — global backprop causes **increasing** interference with block 0 over time.

**Mechanism:** With `detach_lateral=False`, gradients from blocks 1&2 flow backward through the laterals into block 0's parameters. These gradients optimize block 0's representations for the benefit of higher blocks (making its lateral output useful to them), conflicting with block 0's own next-token prediction objective. The lateral_scale=0.2 makes this gradient small but persistent, causing cumulative interference.

**Why blocks 1&2 aren't affected:** Block 2 has no outgoing lateral (topmost in "upward" topology). Block 1's only interference would come from block 2 through one lateral — but lateral_scale=0.2 attenuates this gradient enough to be negligible.

**Cross-horizon (global backprop):** Flat — no specialization.

```
block    1-ahead    2-ahead    4-ahead
  0      4.070      4.071      4.027
  1      3.294      3.291      3.293
  2      3.273      3.272      3.272
```

**Conclusion for Pathway 3 (Local Learning):** Detaching laterals is not a compromise — it's *strictly superior*. The architecture's locality principle isn't just philosophically motivated; it produces better results empirically.
