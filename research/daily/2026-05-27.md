# 2026-05-27 — Architecture made correct

## The insight

The model wasn't doing what Max intended. Three hidden couplings — shared embedding gradients, shared optimizer, wrong temperature for fixed embeddings — each made the blocks less independent than designed. Strip all three and block 0's behavior flips from *getting worse* (5.19→9.58 by step 20, gradient interference) to genuinely learning (5.12→3.85 by step 200).

---

## Fix 1: Carry state explosion → per-timestep normalization

**Problem:** Training crashed at step 80 with NaN.

**Root cause:** Lateral accumulation creates effective gain ~1.08 per timestep (0.9 self + 0.18 from lateral_scale=0.2). Over 128 TBPTT steps: 1.08^128 ≈ 17,000. Hidden states explode.

**Fix:** L2-normalize block states at each timestep in [`core/model.py`](../../core/model.py) (commit [`7aee143`](../../core/model.py)).

**Result:** Stable through 200+ steps, no further NaN.

---

## Fix 2: Separate optimizers + fixed embeddings (the big one)

Per dictations [2026-05-27-8](../../dictations/2026-05-27-8.md) and [2026-05-27-9](../../dictations/2026-05-27-9.md).

**Max's intent:** Blocks are separate networks with separate optimizers. The embedding is shared infrastructure, not a learned coupling point.

**Old setup:** One AdamW for all parameters. Shared embedding trained by all blocks' gradients. Block 0's embedding updates pulled toward what helps blocks 1&2, harming block 0.

**Evidence it was wrong:**

```
Old: block 0 loss goes 5.19 → 9.58 by step 20 (worse than random!)
New: block 0 loss goes 5.12 → 3.85 by step 200 (genuine learning)
```

**Fix:** Fixed random unit-vector embeddings (`requires_grad=False`) + one AdamW per block. Commit [`6250ccd`](../../runs/assembled_architecture.py).

---

## Fix 3: Temperature mismatch

**Observation:** Block 0 initializes at CE=5.19. Random uniform over 62 chars = ln(62) = 4.13. Why worse than random?

**Analysis:** With temperature τ=0.07 and random unit embeddings in 96D, dot-product std ≈ 1/√96 ≈ 0.102. Dividing by 0.07 → logit std ≈ 1.46. This creates randomly peaked softmax distributions ("random overconfidence"), pushing expected CE to ~5.19 — exactly matching observation.

Temperature 0.07 was tuned for *learned* embeddings where the space adapts. Fixed random embeddings need τ≈0.5 (gives init CE≈4.15, near uniform).

**Fix:** τ = 0.07 → 0.5. Commit [`281969a`](../../runs/assembled_architecture.py). Sanity check confirmed init CE = 4.15.
