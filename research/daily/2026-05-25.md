# 2026-05-25 — Tied-depth "instability" was a confounded comparison

## The confound

Overnight tied-depth experiment finished (4 variants × 2 seeds, WikiText-103 char-level). The initial read was alarming: tied_8iter diverges on seed 43, plateaus at 2.549 from step 5K onward. "Weight sharing is fundamentally unstable" was the interim narrative. The adversarial review gate killed it.

The problem: tied_8iter uses `token_injection=block0` (tokens enter once, hidden state iterates 8×). distinct_matched uses `token_injection=all` (fresh tokens every block). So the comparison conflates three things simultaneously — weight sharing, token routing, and block shape (one d=256 block vs eight d=146 blocks). You can't attribute the failure to any one of them.

On the seed where tied_8iter converges (seed 42), it *beats* distinct_matched: 1.798 vs 1.818. On the seed where it fails (seed 43), the lack of token re-injection after iteration 1 is as plausible an explanation as weight sharing itself — there's no anchoring signal to recover from early drift.

## The clean test: weight sharing isolated

To actually test Pathway 1 at this scale, both variants need identical routing. Added a `tied_weights` flag to `ParallelDiagonalModel` in `core/model.py`. The new experiment (`runs/tied_sharing.py`):

- **tied_shared:** 8 blocks, shared weights, d=146, ff=584, `token_injection=all`
- **distinct_matched:** 8 distinct blocks, same config

Same routing, same topology, same FLOPs. Only difference: whether blocks share parameters.

- tied_shared: 1,649,102 params (the reduction IS the point — sharing's benefit is parameter efficiency)
- distinct_matched: 2,847,908 params
- 3 seeds (42, 43, 44)

Sanity-checked, committed, queued behind C_old.

## C_old ablation (complete — 22:27 NZST)

**Result: CLEARLY LATERAL HELPS.** Cross-block communication is genuinely load-bearing.

Both seeds concordant, both above the 0.015 "clearly helps" threshold. The gain (0.030 nats) is 6× the stale-read noise floor.

Readout ablation confirms ALL four blocks contribute — block0_only loses +1.5 nats (catastrophic). This is not a spectator architecture.

**Implication:** Pathway 3 prerequisite met. The bridge experiment (full-backprop vs detached-lateral) is now unlocked — can blocks learn useful communication without cross-block gradient?
