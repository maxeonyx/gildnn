# 2026-05-25 — Tied-depth "instability" was a confounded comparison

## The confound

Overnight tied-depth experiment finished (4 variants × 2 seeds, WikiText-103 char-level). The initial read was alarming: tied_8iter diverges on seed 43, plateaus at 2.549 from step 5K onward. "Weight sharing is fundamentally unstable" was the interim narrative. The adversarial review gate killed it.

The problem: tied_8iter uses `token_injection=block0` (tokens enter once, hidden state iterates 8×). distinct_matched uses `token_injection=all` (fresh tokens every block). So the comparison conflates three things simultaneously — weight sharing, token routing, and block shape (one d=256 block vs eight d=146 blocks). You can't attribute the failure to any one of them.

On the seed where tied_8iter converges (seed 42), it *beats* distinct_matched: 1.798 vs 1.818. On the seed where it fails (seed 43), the lack of token re-injection after iteration 1 is as plausible an explanation as weight sharing itself — there's no anchoring signal to recover from early drift.

## Temporal-window implementation (complete, 23:00–23:30 NZST)

Code prepared and verified on CPU. Three conditions:

- **B0:** No auxiliary branch (baseline, d=211, ff=848, 2 blocks, 2.85M params)
- **H8:** True 8-step history via `window_proj(concat([x_{t-7},...,x_t]))` (3.21M params)
- **C8:** Duplicated current state ×8 through same `window_proj` (3.21M params, same-capacity control)

Key code fixes to `core/model.py`: `bias=False` on `window_proj` (removes bias-channel confound), additive auxiliary branch (preserves current_lower at 0.5 in all conditions), new `temporal_window_mode` parameter ("history" vs "current").

Primary comparison is H8 vs C8 — does real trajectory help more than duplicated-current? H8 and C8 are parameter-matched. Sanity-checked on CPU, all three variants produce expected parameter counts.

## Theory: what temporal trajectories contain (23:30 NZST)

Added a theory section to the temporal-window README. Key insight: C8 is **mathematically exactly** a reparameterized current-state-only model (not "approximately"). The projection `W[x_t;...;x_t] = (Σ_k A_k)·x_t` collapses to the diagonal subspace. All temporal diversity is exclusively available to H8.

H8 implements a learned FIR (finite impulse response) temporal filter — can compute any linear combination of the 8 states, including finite differences (velocity), weighted averages, and lag-specific features. Cannot compute nonlinear cross-time interactions.

Most plausible useful signals (ranked): derivatives/direction of change, trend/persistence, lag timing, short temporal motifs. A positive result means block 0's current state is not sufficient for this downstream use at this scale/budget — does not prove trajectory is fundamentally necessary.
