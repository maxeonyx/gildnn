## The finding

Bands 2-7 never encoded anything token-useful in any prior experiment. Today: attention readout pushed band 2 to 20.8% (from a 14-15% random floor), and per-band CE got *all eight bands* learning within 30 steps. The gradient audit shows why nothing else worked — the local prediction loss is 4-14× stronger than any global signal reaching higher bands, and it's orthogonal to token prediction (cosine 0.013).

Bands 1-2 got lucky: early CE was proportionally strong enough (1.3-1.9× ratio) to establish token-useful features before attention locked onto them. Bands 3+ never had a window.

## Per-band CE: existence proof, not the solution

**Correction (dictation 2026-05-31-01):** Per-band CE — giving each band a token prediction loss at its own horizon — is an unprincipled hack. It broadcasts a global objective (token prediction) to every level. Max's architecture demands one CE head on band 0 only; everything else learns from local objectives (predicting neighbors, not predicting tokens). Per-band CE is informative as an *existence proof* that the architecture can specialize, but it is not the intended learning rule.

`--per-band-ce` gives band *b* a CE loss predicting the token at `min(2^b, 64)` steps ahead. Gradient stays local. No shared parameters between bands. 30-step sanity check:


Fast bands (1-2, rates 2-4) oscillate — they fire frequently and get many competing gradient updates. Slow bands (3-7, rates 8-128) converge stably. This suggests per-band learning rate scaling (inversely proportional to firing rate) would help.

The correlation IS the correct signature: shared language-model substrate, specialized projections.

The fixed readout (normalized dot product against token embeddings) was optimized through CE on band-0 only. Bands 1-7's horizon-specialized features are in a representation space incompatible with this readout. This isn't a deficiency of the bands — it's a readout limitation.

## Confirming the null

MSI + cross-band negatives finished at 2000 steps. Final lag probe: band 0 = 36.7%, band 1 = 21.4%, bands 2-7 = 14-15%. Same as every other configuration that lacks per-band task signal. The input-side and diversity interventions are definitively closed.

## What this tells us

Two boundary conditions, one from each side:

**InfoNCE** (local neighbor prediction) is architecturally correct — each module learns from its neighborhood, no global signal. But it's orthogonal to token prediction (cosine 0.013). It creates structure (orthogonal bands), but structure ≠ useful structure. Generic self-supervised objectives are not automatically good local learning signals.

**Per-band CE** (each band predicts tokens at its own horizon) creates rapid specialization — all bands below entropy in 30 steps. But per the dictation correction above, it's architecturally wrong: it broadcasts a global token-prediction objective to every level. The specialization it produces is real, but the mechanism violates the local-learning principle.

Together they bracket the problem precisely: *what local neighborhood objective is both genuinely local (no global token signal) and task-aligned enough to produce useful multi-timescale representations?*

The anti-token representations in bands 5-7 under per-band CE (scoring below random on token probes) suggest genuine abstraction. Whether this kind of representation can emerge from a truly local objective is the open question.

## Full-stack experiment (in progress, architecturally rejected)

The capstone experiment (per-band CE + attention readout + detached readout) is still running as of this writing. Its premise — per-band CE — has been rejected by the dictation above. The results, if they arrive, are diagnostic: they answer "can a learned readout exploit forced specialization?" but not "can the architecture specialize with local learning alone?"

## Where the project ends

The project did not find the right local learning rule. It found the shape of the missing piece.

The architecture works: 192 modules, multi-rate bands, detached laterals, noise-driven information hierarchy. Band 0 learns token prediction (CE 2.54). The machinery for specialization exists — per-band CE proves the architecture can support it. But the local learning signal that would make it emerge without global token supervision remains an open question.

Promising directions for a future session (from dictation 2026-05-30-03): predictive coding, contrastive Hebbian learning, communication through coherence, phase-amplitude coupling. The key constraint: the signal must be local (neighborhood-only) and must create representations that differ across timescales, not just across spatial positions.
