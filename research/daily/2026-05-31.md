# 2026-05-31 — The architecture needed per-band task signal all along

## The finding

Bands 2-7 never encoded anything token-useful in any prior experiment. Today: attention readout pushed band 2 to 20.8% (from a 14-15% random floor), and per-band CE got *all eight bands* learning within 30 steps. The gradient audit shows why nothing else worked — the local prediction loss is 4-14× stronger than any global signal reaching higher bands, and it's orthogonal to token prediction (cosine 0.013).

## The gradient audit

A new diagnostic (`experiments/automaton_graph/grad_audit.py`) measures CE vs local gradient magnitude per band. At initialization, CE distributes evenly (~6.5 L2 per band) while local loss scales with firing rate — band 7 gets 14× more local gradient than CE gradient:

```
At initialization:
         CE grad    Local grad    Ratio (local/CE)
band 0      6.53         0.00         —  (no local loss)
band 1      6.60         8.54         1.3×
band 2      6.53        12.59         1.9×
band 3      6.55        18.55         2.8×
band 4      6.52        29.64         4.5×
band 5      6.39        49.62         7.8×
band 6      6.22        69.98        11.2×
band 7      5.90        84.39        14.3×
```

After 500 steps, the picture collapses further. Attention converges on bands 0-1, so CE gradient to higher bands drops to ~0.27 — a 44× disadvantage vs local loss:

```
After 500 steps:
         CE grad    Local grad    Ratio
band 0      0.63         0.00         —
band 1      0.27        11.71        44×
band 2      0.29        10.42        36×
band 3-7:  0.26-0.30    3-11        18-44×
```

Global gradient cosine between CE and local: **0.013** — effectively orthogonal. The two objectives push in completely unrelated directions. Bands 1-2 got lucky: early CE was proportionally strong enough (1.3-1.9× ratio) to establish token-useful features before attention locked onto them. Bands 3+ never had a window.

## Per-band CE: the faithful solution

The attention readout is informative but unfaithful — it violates module independence by routing global CE gradient into all bands. The correct design is already in the architecture spec: each band predicts the token at its own horizon.

`--per-band-ce` gives band *b* a CE loss predicting the token at `min(2^b, 64)` steps ahead. Gradient stays local. No shared parameters between bands. 30-step sanity check:

```
Per-band CE (step 10 → step 30):
b0: 3.40 → 3.24  (horizon +1)
b1: 3.72 → 3.49  (horizon +2)
b2: 4.00 → 3.64  (horizon +4)
b3: 4.13 → 3.76  (horizon +8)
b4: 4.51 → 3.82  (horizon +16)
b5: 4.56 → 4.11  (horizon +32)
b6: 4.33 → 4.05  (horizon +64)
b7: 4.72 → 4.23  (horizon +64, capped)
```

Entropy baseline for this vocabulary is 4.17. All bands are below it or converging rapidly by step 30. In every prior experiment, bands 2-7 never encoded *anything* token-useful after thousands of steps. This took 30.

The 2000-step run is in progress. If the lag-spectrum probe shows different bands specializing on different temporal spans, that's the first real evidence of the multi-rate separation the architecture was designed to produce.

## Confirming the null

MSI + cross-band negatives finished at 2000 steps. Final lag probe: band 0 = 36.7%, band 1 = 21.4%, bands 2-7 = 14-15%. Same as every other configuration that lacks per-band task signal. The input-side and diversity interventions are definitively closed.

## What this tells us

The lateral prediction loss was always orthogonal to the token task (cosine 0.013). It builds interesting dynamics — broadcast propagation, mid-rate convergence — but never forces bands to encode *different temporal information*. Per-band horizon CE does, by construction: band 4 can't predict 16 steps ahead using the same features band 0 uses for 1 step ahead.
